# 苍岚大陆 —— 标签驱动的 TRPG 文字冒险

一款基于 **C# / .NET 8 + Avalonia UI 11** 的桌面文字冒险游戏（TRPG）。世界由「标签」驱动：种族进化、职业转职、任务推进、NPC 关系、采集制造全部由标签条件触发；本地 AI（LLamaSharp 直连 GGUF 模型）为 NPC 对话提供自由文本生成，离线自动降级，永不阻塞游戏。

## 特性

- **四步页面流程**：开始界面 → 存档选择（3 存档位）→ 角色创建（种族/职业/特质点选）→ 游戏
- **全行动空间化**：行动按钮随玩家坐标动态变化——村庄里没有怪物与采集点，走出村庄才会遇到；攻击/采集/交谈/招募/布告板/家园/建造/制造/喝水都有位置门槛
- **传闻引导**：不知道去哪时点「传闻」，播报最近目标的方向与距离
- **图驱动成长**：12 种族进化图、8 职业转职图、28 任务图，创建时只列根种族（5）与基础职业（4）
- **战争迷雾**：多层地图（地表/地下/天空），圆形视野随移动更新
- **生存系统**：饱食/水分/体温，生态区影响消耗
- **本地 AI**：LLamaSharp 直连 GGUF 文件（不依赖服务进程），不可用时自动回退规则对话
- **存档体系**：3 存档位，自动存档 + 手动存档，恢复家园/迷雾/好感/声望

## 目录结构

```
├── src/
│   ├── GameCore/       # 游戏核心（无 UI 依赖）：标签/图/战斗/生存/存档/AI…
│   ├── GameApp/        # Avalonia 桌面客户端（MVVM）
│   └── GameDemo/       # 控制台演示（核心系统跑通示例）
├── tests/
│   ├── GameCore.Tests/ # 核心测试（75 项）
│   └── UiSmoke/        # UI 冒烟（页面流程 + 空间化断言）
├── data/               # 全部 JSON 配置（种族/职业/任务/怪物/NPC/物品…）
└── Test.sln
```

## 构建与运行

```bash
# 运行桌面版
dotnet run --project src/GameApp

# 测试
dotnet run --project tests/GameCore.Tests   # 75 项核心测试
dotnet run --project tests/UiSmoke          # UI 冒烟

# 发布 Windows 自包含版
dotnet publish src/GameApp/GameApp.csproj -c Release -r win-x64 --self-contained true -o publish/win-x64
```

## 本地 AI 模型（可选）

游戏在 `C:\GameModels`（纯 ASCII 路径）查找 GGUF 模型文件，存在则启用本地对话生成，缺失则自动降级为规则对话，不影响游玩。

## 玩法速览

- 移动用「东/南/西/北」按钮；「环顾四周」查看附近；「传闻」探听最近目标方向
- 村里可交谈、招募、看布告板接委托、在水井喝水；怪物与采集点都在村外
- 采集点有储量与冷却；制造/建造需回到家园
